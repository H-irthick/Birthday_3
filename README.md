# Happy Birthday Disha! 💖

A beautiful, interactive birthday website created with love and care. This project features a stunning homepage with birthday wishes, a photo gallery of memories, and special notes.

## Features

- ✨ **Interactive Homepage**: Beautiful animations, confetti effects, and smooth scrolling
- 📸 **Memories Gallery**: Full-screen photo gallery with 31 beautiful memories
- 💝 **Special Notes**: Heartfelt messages and personal notes
- 🌙 **Dark/Light Theme**: Toggle between themes with system preference detection
- 📱 **Responsive Design**: Works perfectly on all devices
- 🎨 **Modern UI**: Glass morphism effects, smooth animations, and beautiful typography

## Hosting Options

### 1. GitHub Pages (Free & Easy)

1. **Create a GitHub repository**:
   - Go to [GitHub](https://github.com) and create a new repository
   - Name it something like `birthday-disha` or `disha-birthday`

2. **Upload your files**:
   - Upload all files from this folder to your repository
   - Make sure `index.html` is in the root directory

3. **Enable GitHub Pages**:
   - Go to your repository settings
   - Scroll to "Pages" section
   - Select "Deploy from a branch" → "main" branch
   - Your site will be available at `https://yourusername.github.io/repository-name`

### 2. Netlify (Free & Fast)

1. **Go to [Netlify](https://netlify.com)**
2. **Drag and drop** your entire project folder
3. **Get instant deployment** with a custom URL
4. **Optional**: Connect to GitHub for automatic deployments

### 3. Vercel (Free & Modern)

1. **Go to [Vercel](https://vercel.com)**
2. **Import your project** from GitHub or upload directly
3. **Deploy instantly** with global CDN

### 4. Firebase Hosting (Free)

1. **Install Firebase CLI**: `npm install -g firebase-tools`
2. **Initialize project**: `firebase init hosting`
3. **Deploy**: `firebase deploy`

### 5. Traditional Web Hosting

Upload all files to your web hosting provider's public_html or www folder.

## Customization

### Changing the Name
- Edit the name "Disha" in all HTML files
- Update the title tags and headings

### Adding More Photos
1. Add new images to the `assets/` folder
2. Update `pages/memories.html` with new image sections
3. Add corresponding navigation dots

### Modifying Colors
- Edit the CSS variables in `assets/styles.css`
- Change the `--accent-1` and `--accent-2` variables for different color schemes
